== Inline Formatting

*_bold italic_*, `*mono bold*`, and _`italic mono`_.
A word with pass:[<b>raw HTML</b>] embedded via passthrough.

Superscript: E = mc^2^.
Subscript: H~2~O is water.

A line with a footnote.footnote:[This is the footnote text that appears at the bottom.]

Escaped formatting: \*not bold\*, \_not italic\_.

Constrained vs unconstrained: **un**constrained bold, __un__constrained italic.

[source,rust]

fn fibonacci(n: u64) -> u64 {
    match n {
        0 => 0,
        1 => 1,
        _ => fibonacci(n - 1) + fibonacci(n - 2),
    }
}
----

[source,python]
----
def merge_sort(arr: list[int]) -> list[int]:
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
----

public record Point(double X, double Y)

.Calculating compound interest
====
The formula for compound interest is:

A = P(1 + r/n)^nt^

Where:

* A = final amount
* P = principal
* r = annual interest rate
* n = compounding frequency
* t = time in years
====
