.Long register table

|===
|Offset |Name |Description

|0x00 |Control |Enables the device and selects its mode of operation.
|0x04 |Status |Reports the device state, errors and pending events.
|0x08 |Config |Holds the configuration loaded at reset.
|0x0C |Data |The data register, read and written by the host.
|0x10 |Mask |Interrupt mask bits, one per event.
|0x14 |Events |Pending events, cleared by writing ones.
|0x18 |Timer |A free-running timer in microseconds.
|0x1C |Compare |Raises an event when the timer reaches it.
