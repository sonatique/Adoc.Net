== Code Blocks

Here is a C# code example with syntax highlighting label:

[source,csharp]
----
var options = new PdfRenderOptions
{
    FontSize = 11f,
    TitleFontSize = 24f,
    HeadingScale = 0.85f,
    LineSpacing = 1.35f,
    ShowPageNumbers = true,
    FooterText = "Page {page} of {pages}",
    LinkColor = new PdfColor(0f, 0f, 0.8f),
};

byte[] pdf = new PdfRenderer()
    .RenderToBytes(document, options);

=== Column-Weighted Table

[cols="1,3"]
|===
| Key | Description

| `FontSize`
| Base body text font size in points. Default is 11. Controls the size of paragraph text throughout the document.

| `HeadingScale`
| Scale factor applied to each heading level. H2 = TitleFontSize x scale, H3 = H2 x scale, and so on. Default 0.85.

| `LineSpacing`
| Line spacing multiplier. The leading (distance between baselines) is calculated as fontSize x lineSpacing. Default 1.35.
|===

== Admonitions

NOTE: This document showcases all the new features added in beta.3 of AdocNet's PDF renderer.

TIP: Use `PdfRenderOptions` to customize every aspect of the PDF output, from page size to font sizes to visual styling.

WARNING: Interlaced PNGs are not supported. The renderer will fall back to a placeholder for these images.

IMPORTANT: PDF output is fully deterministic. Rendering the same document twice always produces byte-identical output.

== Description Lists

Font embedding:: TrueType fonts are parsed, subsetted to include only used glyphs, and embedded as CIDFontType2 objects with ToUnicode CMaps for proper text extraction.

Image support:: JPEG images use DCTDecode (raw passthrough). PNG images are decompressed, de-filtered, and re-compressed with FlateDecode. RGBA PNGs get a separate SMask for transparency.

Page layout:: The renderer uses a simple vertical flow model with configurable page size, margins, and content width. No floats or multi-column support.
