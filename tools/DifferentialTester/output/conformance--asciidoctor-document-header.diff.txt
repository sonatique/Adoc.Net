  <h2 id="_header_requirements_per_doctype">Header requirements per doctype</h2>
  <p>The header is optional when the <code>doctype</code> is <code>article</code> or <code>book</code>.
  A header is required when the document type is <code>manpage</code>.
- See the <a href="asciidoctor:manpage-backend:index.html">manpage doctype</a> section for manual page (man page) requirements.</p>
+ See the xref:asciidoctor:manpage-backend:index.adoc[manpage doctype] section for manual page (man page) requirements.</p>
  <p>If you put content blocks above the document header when using the default article doctype, you will see the following warning:</p>
  <pre>level 0 sections can only be used when doctype is book</pre>
  <p>While this warning can be mitigated by changing the doctype to book, it may lead to a secondary warning about an invalid part.
  That's because the document title will be repurposed as a part title and any lines that follow it as content blocks.
- If you're going to use the book doctype, you must structure your document to use <a href="sections:parts.html">sections:parts.html</a>.</p>
+ If you're going to use the book doctype, you must structure your document to use xref:sections:parts.adoc[].</p>
  <h2 id="_header_processing">Header processing</h2>
  <p>The information in the document header is displayed by default when converting to a standalone document.
  If you don't want the header of a document to be displayed, set the <code>noheader</code> attribute in the document's header or via the CLI.</p>
